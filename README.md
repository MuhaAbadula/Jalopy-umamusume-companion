# Umamusume companion

Мод для Jalopy с JaLoader. Выберите спутницу в настройках мода и перезапустите игру.
Удерживайте **V**, наведите мышь на команду и отпустите клавишу. Можно попросить
спутницу выйти из машины, идти за вами, ждать, вернуться в машину или забрать ящик.
Клавишу меню можно изменить в настройках.

## Установка и обновление

1. Закройте Jalopy. При обновлении перенесите старые `FukuUncle.dll` и
   `UmaCommands.dll` из `Jalopy_Data/Mods` в папку для резервной копии.
2. Распакуйте установочный архив в каталог с `Jalopy.exe`. Если вы меняли
   реплики или текстуры, предварительно сохраните свои версии.
3. Запустите игру и откройте **Umamusume companion** в меню JaLoader.

Для совместимости с прежними сохранениями мод использует идентификатор
`FukuUncle`. Модели, радио и дорожные ресурсы находятся в
`Jalopy_Data/Mods/Assets/FukuUncle`. Настройки спутницы и прежнюю клавишу
команд мод читает из сохранений JaLoader.

## Сборка из исходников

Установите .NET SDK, Jalopy и JaLoader. В корне проекта выполните команду,
подставив путь к игре.

```powershell
dotnet build UmamusumeCompanion.csproj -c Release "-p:GameDir=D:\SteamLibrary\steamapps\common\Jalopy"
```

Сборка создаёт `bin/Release/net35/UmamusumeCompanion.dll`. Скопируйте DLL в
`Jalopy_Data/Mods`. Для запуска из исходников понадобятся ресурсы спутницы
из установочного архива или прежней установки FukuUncle. Тексты из `models/`
накладываются на одноимённые папки моделей, а файлы из `Paintjobs/` идут
в папку `Paintjobs` рядом с исполняемым файлом игры.

## Структура

- `src/Core` содержит точку входа JaLoader и регистрацию настроек.
- `src/Commands` отвечает за круговое меню и доступность команд.
- `src/Travel` содержит выход из машины, погрузку, ночлег и возвращение к машине.
- `src/Characters` отвечает за модели, анимации, голос и поведение спутниц.
- `src/Paint`, `src/Radio`, `src/Luck`, `src/Pranks` и `src/Experiments`
  содержат соответствующие игровые механики.
- `src/Integration` содержит патчи игры, а `src/Diagnostics` — панель отладки.
