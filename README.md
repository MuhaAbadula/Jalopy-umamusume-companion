> [!IMPORTANT]
> ## Мод для Jalopy полностью сделан вайбкодингом
> Я описывал, как должна вести себя спутница, а код мода писал ИИ.

В поездку можно взять одну из пяти спутниц. Удерживайте **V**, наведите мышь
на команду и отпустите клавишу. Спутницу можно попросить выйти из машины,
идти за вами, подождать, вернуться в машину или забрать ящик.

**[Скачать Umamusume companion 0.55.1 для Jalopy (ZIP, 105 МБ)](https://github.com/MuhaAbadula/Umamusume-companion/releases/download/v0.55.1/Umamusume-companion-0.55.1.zip)**

## Установка

1. Установите JaLoader для Jalopy и закройте игру. [Инструкция автора JaLoader](https://github.com/theLeaxx/JaLoader/wiki/Installing-JaLoader-via-JaPatcher).
2. Скачайте установочный ZIP по ссылке выше. На странице релиза этот файл называется `Umamusume-companion-0.55.1.zip` и находится в разделе **Assets**.
3. Откройте папку с `Jalopy.exe`. В Steam её можно открыть из библиотеки через контекстное меню Jalopy → **Управление** → **Просмотреть локальные файлы**.
4. Распакуйте **содержимое** архива в эту папку, объединив одноимённые каталоги. При стандартной установке JaLoader файл мода окажется в `Jalopy_Data/Mods/UmamusumeCompanion.dll`, модели — в `Jalopy_Data/Mods/Assets/UmamusumeCompanion/models/`, а папка `Paintjobs` — рядом с `Jalopy.exe`. Если в JaLoader выбрана другая папка модов, перенесите в неё содержимое `Jalopy_Data/Mods` из архива.
5. Запустите Jalopy и найдите **Umamusume companion** в списке модов JaLoader. Выберите спутницу в настройках мода и перезапустите игру. В поездке удерживайте **V**, чтобы открыть меню команд.

### Обновление с предыдущей версии

Перед распаковкой сохраните копию своих моделей, реплик и радио. Если раньше
спутница и команды устанавливались двумя отдельными DLL, перенесите обе старые
DLL из папки модов в резервную папку. При первом запуске мод перенесёт найденные
настройки и журналы в `ModSaves/UmamusumeCompanion`.

## Сборка из исходников

Установите .NET SDK, Jalopy и JaLoader. В корне проекта выполните команду,
подставив путь к игре.

```powershell
dotnet build UmamusumeCompanion.csproj -c Release "-p:GameDir=D:\SteamLibrary\steamapps\common\Jalopy"
```

Сборка создаёт `bin/Release/net35/UmamusumeCompanion.dll`. Скопируйте DLL в
`Jalopy_Data/Mods`. Для запуска из исходников понадобятся ресурсы спутницы
из установочного архива или прежней установки мода. Тексты из `models/`
накладываются на одноимённые папки моделей, а файлы из `Paintjobs/` идут
в папку `Paintjobs` рядом с исполняемым файлом игры.

Состав пакета, портрет Nice Nature и заметки по её сценам собраны в [справочнике спутниц](docs/companions.md).

## Структура

- `src/Core` содержит точку входа JaLoader и регистрацию настроек.
- `src/Commands` отвечает за круговое меню и доступность команд.
- `src/Travel` содержит выход из машины, погрузку, ночлег и возвращение к машине.
- `src/Characters` отвечает за модели, анимации, голос и поведение спутниц.
- `src/Paint`, `src/Radio`, `src/Luck`, `src/Pranks` и `src/Experiments`
  содержат соответствующие игровые механики.
- `src/Integration` содержит патчи игры, а `src/Diagnostics` — панель отладки.
